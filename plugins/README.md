# A quick list of the plugins available in this shell.

-# They are not installed with the shell.
Each plugin can be installed separately from *Nexus → Plugins.*

`index.json` is the index file that the shell uses to fetch plugins.
It basically selects a subdirectory (which would be a plugin), so that the installer shallow-clones the repository moves it into `~/.local/share/caelestia/plugins/<id>`.

-# Organized as: Path → ID → Quick description

`plugin-desktop-lyrics` → `deeadly137/desktoplyrics` → Synchronized lyrics on desktop

`plugin-desktop-pet` → `deeadly137/desktoppet` → Shimeji desktop pet

`plugin-livewallpaper` → `deeadly137/livewall` →  GIF / Wallpaper Engine support

`plugin-nebula-widgets` → `deeadly137/nebulawidgets`→ Nebula Shell-style desktop widgets

`plugin-wallhaven` → `deeadly137/wallhaven` → Wallhaven browser/downloader

`plugin-dim-essentials` → `deeadly137/dimessentials` → Features that everyone got used to in MiDnight Shell.

`plugin-pipmanager` → `deeadly137/pipmanager` → Picture in Picture auto-align with a utilities card

`plugin-clipboard` → `deeadly137/clipboard` → Clipboard history and favourites in the launcher

`plugins/better-lyrics` ([LonelyOmen/caelestia-plugins](https://github.com/LonelyOmen/caelestia-plugins)) → `xlonely/betterlyrics` → Better Lyrics desktop lyrics
